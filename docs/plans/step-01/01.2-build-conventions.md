## Stage decisions

- **Included build** `convention-plugins/` подключается через
  `pluginManagement { includeBuild("convention-plugins") }`. Precompiled script plugins:
  - `tgvd.kmp` — `jvm()` + `js(IR) { browser() }`, toolchain 21, Kotest через JUnit 5 в `jvmTest`,
    тест-таск JS-браузера выключен (`compileTestKotlinJs` остаётся и компилирует commonTest под JS);
  - `tgvd.kmp.serialization` — `tgvd.kmp` + serialization;
  - `tgvd.compose` — `tgvd.kmp` + compose + compose compiler (для `features`);
  - `tgvd.compose.js` — только `js(IR) { browser() }` + compose + compose compiler + serialization
    (для `tgminiapp`); `binaries.executable()` и `outputFileName` остаются в модуле;
  - `tgvd.jvm`, `tgvd.jvm.serialization` — для `server:*`.
  - Toolchain — константа в `BuildConventions.kt` (`JVM_TOOLCHAIN_VERSION = 21`).
  - Все `Test`-таски: `useJUnitPlatform()` и `jvmArgs("-Dapi.version=1.40")` (Testcontainers с
    Docker Engine 29+, см. `convention-plugins.md`).
- **Плагины семейства Kotlin и Compose** (`kotlinJvm`, `kotlinMultiplatform`, `kotlinSerialization`,
  `composeMultiplatform`, `composeCompiler`) применяются **только** через конвенции (маркеры — в
  `convention-plugins/build.gradle.kts`). `ktor` и `shadow` остаются `alias(...)` в `server:app`.
  Если возникнет конфликт classpath — применять и их по id через маркеры; записать в notes.
- **Kotest.** Kotest Gradle plugin и KSP убираются из `domain` и `api:contract`; Kotest на JVM через
  `kotest-runner-junit5`. JS-раннер не нужен (G11).
- **Каталог версий.**
  - Testcontainers — все артефакты одной версии 2.x. В 2.x артефакты переименованы:
    `org.testcontainers:testcontainers-postgresql` (версия `2.0.3` есть на Maven Central);
    JUnit-интеграцию — сверить координаты на Maven Central до правки. `org.testcontainers:postgresql:1.21.4` удалить.
  - Удалить записи с нулём использований — как минимум `exposed-dao`, `composeHotReload`; остальные
    найти `grep` по каждому alias. Список удалённого — в notes.
  - Версии остальных библиотек не поднимаем.
- **Корневой `build.gradle.kts`** — только чтение `app.version` и `group`/`version` для всех
  проектов (`allprojects { group = …; version = … }` без репозиториев), без `plugins {}` и
  без `subprojects {}`.
- **Репозитории** переезжают в `settings.gradle.kts` → `dependencyResolutionManagement`
  (`repositoriesMode = FAIL_ON_PROJECT_REPOS`):
  - `mavenCentral()`, `google()`;
  - GitHub Packages `https://maven.pkg.github.com/alelk/tg-mini-app` с прежним разрешением кредов:
    `gpr.user` → `GITHUB_USER` → дефолт `alelk`; `gpr.token` → `GITHUB_TOKEN`;
  - `mavenLocal()` последним, с `content { includeGroup("io.github.alelk") }`.
- **Composite build `../tg-mini-app`** (условный `includeBuild` с `dependencySubstitution`
  `io.github.alelk:tg-mini-app`) сохраняется как есть; исправить только сообщение «pws-core» →
  «tg-mini-app». Сборка должна проходить и с локальной папкой `../tg-mini-app`, и без неё.
- **Settings.** `enableFeaturePreview("TYPESAFE_PROJECT_ACCESSORS")`; все `project(":x")` в
  `build.gradle.kts` → `projects.x`.
- **`shadowJar`** снимается с `build`. Имя `tgvd-server.jar` и путь `server/app/build/libs/` не меняются.
  - `ci.yml`, шаг «Build and Test»: `./gradlew build :server:app:shadowJar :tgminiapp:jsBrowserDistribution --no-daemon`
    (`check` входит в `build`).
  - `server/app/Dockerfile` и `Dockerfile.tgvd-server` уже вызывают `:server:app:shadowJar` явно —
    проверить, не менять.
  - `.releaserc.yaml` прикладывает `server/app/build/libs/tgvd-server.jar` — CI должен собирать его
    до шага Release.
- **`gradle.properties`**: `org.gradle.parallel=true`, `org.gradle.caching=true`. Configuration
  cache в этой стадии не включаем.
- **Мина стадии.** При снятии Kotest-плагина тесты могут тихо перестать запускаться (зелёный build
  с нулём тестов). Число JVM-тестов до и после обязано совпасть.

## Work

1. Базовая линия: `./gradlew clean build`, подсчёт JVM-тестов по модулям (команда в Checks).
   Записать в notes.
2. Создать `convention-plugins/` по шаблону скилла.
3. Переводить модули на конвенции по одному; после каждого — `./gradlew :<module>:build`.
4. Репозитории в settings, убрать `subprojects {}`, typesafe accessors, `projects.x`.
5. Убрать Kotest-плагин и KSP, выровнять Testcontainers, почистить каталог.
6. Снять `shadowJar` с `build`, обновить `ci.yml`.
7. `gradle.properties`.
8. Повторить подсчёт тестов.

## Checks

```bash
./gradlew clean build
./gradlew :server:app:shadowJar && test -f server/app/build/libs/tgvd-server.jar
./gradlew :tgminiapp:jsBrowserDistribution
# все три должны вернуть пусто:
grep -rnE 'alias\(libs\.plugins\.(kotlin|compose)' --include=build.gradle.kts . | grep -v convention-plugins
grep -rn jvmToolchain --include=*.kts . | grep -v convention-plugins
grep -rn 'project(":' --include=*.kts .
# число JVM-тестов (до и после — одинаковое):
find . -path '*/build/test-results/*' -name 'TEST-*.xml' -not -path './convention-plugins/*' \
  -exec grep -c '<testcase' {} + | awk -F: '{s+=$NF} END {print s}'
```

## Done when

- Все модули собираются через `tgvd.*`; корневой build без `subprojects`; репозитории в settings.
- Число JVM-тестов до и после совпадает (оба числа в notes); `tgvd-server.jar` и JS-дистрибутив
  собираются; CI-команда обновлена.

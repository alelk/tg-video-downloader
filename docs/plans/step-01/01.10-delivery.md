## Stage decisions

- Пути всех Dockerfile и имена образов не меняются.
- **Builder-стадии** (`server/app/Dockerfile`, `Dockerfile.tgvd-server`, `tgminiapp/Dockerfile`)
  собирают через `./gradlew` репозитория (wrapper 9.7.1), а не через `gradle` образа
  `gradle:8.14-jdk21`: базовый образ — JDK 21 (например `eclipse-temurin:21-jdk`), wrapper и
  `gradle/` копируются в контекст. Build args `GITHUB_USER`/`GITHUB_TOKEN` остаются (BuildKit
  secrets не в скоупе).
- `Dockerfile.ci` (сборка из готовых артефактов) не меняются, кроме `ENTRYPOINT` из 01.5.
- **`ci.yml`.**
  - Верхнеуровневые `permissions: contents: read`; права на запись — только джобе/шагу
    semantic-release (`contents: write`, `issues: write`, `pull-requests: write` — ровно то, что
    нужно плагинам из `.releaserc.yaml`).
  - `concurrency: { group: ci-${{ github.ref }}, cancel-in-progress: ${{ github.event_name == 'pull_request' }} }`.
  - `timeout-minutes` на джобах; `gradle/actions/setup-gradle` для кэша.
  - Гейт-команда — из 01.2 (`./gradlew build :server:app:shadowJar :tgminiapp:jsBrowserDistribution --no-daemon`);
    в Actions нужен Docker для Testcontainers (есть на `ubuntu-latest`).
- **`docker-publish.yml`** — то же ужесточение (`permissions` минимальные, `packages: write` только
  где пушится образ; `concurrency`; `timeout-minutes`).
- **`.dockerignore`** дополнительно исключает `.claude`, `data/`, `output/`, `yt-dlp`. Исключение
  `kotlin-js-store/` сейчас есть — проверить, не нужен ли `kotlin-js-store/yarn.lock` для
  воспроизводимой JS-сборки в `tgminiapp/Dockerfile`; если нужен — перестать его исключать, решение в notes.

## Work

1. Builder-стадии трёх Dockerfile → `./gradlew`.
2. `.dockerignore`.
3. `ci.yml`, `docker-publish.yml`.
4. Локальная сборка образов, прогон CI на ветке.

## Checks

```bash
./gradlew build :server:app:shadowJar :tgminiapp:jsBrowserDistribution
docker build -f server/app/Dockerfile.ci -t tgvd-server:ci-test .
docker build -f server/app/Dockerfile -t tgvd-server:local-test .
grep -rn 'gradle:8' --include='Dockerfile*' .   # пусто
```

- Контейнер из `Dockerfile.ci` стартует с тестовым конфигом, `/health` отвечает; `docker stop`
  завершает его за секунды (exec из 01.5), а не по таймауту 10 с.
- Прогон CI на ветке зелёный (ссылка на run — в notes).

## Done when

- Все образы собираются wrapper'ом; CI и publish с минимальными правами; release-ассеты те же.

## Stage decisions

- ADR пишется в формате существующих ADR проекта (`# ADR-009: …`, Status/Date/Authors), на
  английском, как остальные ADR; содержание — из Decisions и Forks шага.
- `AGENTS.md` — короткий (цель ≤ 100 строк), кросс-агентный; `CLAUDE.md` — только специфика
  Claude Code и текущая фаза; `docs/PROJECT_CONTEXT.md` — единственный «контекст проекта».
  Факт живёт в одном месте, остальные ссылаются.
- Скиллы: `AGENTS.md` явно говорит, что `.claude/skills/` — локальная git-ignored копия из
  `engineering-ai-skills` (исключение в `.git/info/exclude`), её не редактируют; исключения — ADR-009.
  Как установить копию на новой машине — одна команда-ссылка на `INSTALL.md` скиллов (вариант C).
